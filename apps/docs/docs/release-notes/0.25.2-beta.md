## Fixes and Improvements

- **Ingredient lines keep every word:** A list bullet ("• 2 eggs") no longer hides the amount, and an amount near the end of a line no longer drops the word after it ("Zest of 1 lemon" lost "lemon"). The amount still scales with the servings. This applies to every import and to lines typed in the recipe editor ([#635](https://github.com/norish-recipes/norish/issues/635)).
- **Amounts in the middle of a line:** "potatoes 400 g boiled" now reads as 400 g of "potatoes boiled", so it scales with the servings. A range written with a slash ("10/15 cherry tomatoes") reads as 10, not as a fraction, and "0 to taste" no longer shows a 0.
- **Ingredients written with "di" or "de":** "200 g di farina" now finds flour instead of creating an ingredient called "di farina". Ingredients already created that way that are still waiting for review are merged into the food they name when the server starts.
- **Recipe Keeper import:** Separator lines ("-") no longer become empty steps, and in a list where the export turned some bullets into a full stop, ".80 g" reads as 80 g, not 0.8 g. Import the archive again to fix recipes that were already imported.
